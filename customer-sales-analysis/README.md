# Customer Sales Analysis

An end-to-end portfolio project that turns 180 retail transactions into business insights using Excel-ready data, SQL, Python/Pandas, and an interactive Streamlit dashboard.

## Business questions

- How much revenue and profit did the business generate?
- Which categories, cities, customer segments, and months performed best?
- How do discounts affect profit margin?
- Which products should management prioritize?
- How can the same KPIs be reproduced in SQL, Python, Excel, and Power BI?

## Headline results

|---|---:|
| Orders | 180 |
| Revenue | ₹13,07,961 |
| Profit | ₹3,45,635 |
| Profit margin | 26.4% |
| Average order value | ₹7,266 |
| Average customer rating | 4.0 / 5 |
| Top category by revenue | Furniture (₹9,07,506) |
| Top city by revenue | Mumbai (₹3,38,458) |
| Best month | 2025-02 (₹1,54,323) |

The dataset is synthetic and intentionally included so the analysis is fully reproducible and does not expose customer information.

## Run the Python analysis

```bash
cd customer-sales-analysis
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/analysis.py
```

The script validates the data, removes exact duplicate orders, calculates KPIs, saves summary tables, and creates three charts in `outputs/`.

## Run the interactive dashboard

```bash
streamlit run dashboard/app.py
```

Use the sidebar to filter by date, city, category, and segment. KPI cards and charts update together.

## Use with MySQL

1. Create a schema and import `data/sales.csv` into a table named `sales`.
2. Run `sql/analysis.sql`.
3. Compare the SQL results with the Python-generated output files.

If local file loading is enabled, this pattern can be used after adjusting the path:

```sql
LOAD DATA LOCAL INFILE '/absolute/path/to/sales.csv'
INTO TABLE sales
FIELDS TERMINATED BY ','
ENCLOSED BY '"'
LINES TERMINATED BY '\n'
IGNORE 1 ROWS;
```

## Build the Power BI dashboard

1. Get Data → Text/CSV → choose `data/sales.csv`.
2. Set `order_date` to Date and numeric columns to Decimal/Whole Number.
3. Create measures for Total Revenue, Total Profit, Profit Margin, Orders, and Average Order Value.
4. Add KPI cards, a monthly revenue line chart, category and city bar charts, and slicers for city/category/segment.
5. Cross-check values against the headline results above.

Suggested DAX:

```DAX
Total Revenue = SUM(sales[revenue])
Total Profit = SUM(sales[profit])
Profit Margin = DIVIDE([Total Profit], [Total Revenue])
Orders = DISTINCTCOUNT(sales[order_id])
Average Order Value = DIVIDE([Total Revenue], [Orders])
```
